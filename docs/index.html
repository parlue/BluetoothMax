BluetoothMax

Bluetooth LE gateway for ChessLink chess computer modules -- multi-board, standalone mode, automatic PGN recording

BluetoothMax bridges a cable-connected chess computer module (MILLENNIUM King, Mephisto Phoenix) to any of several wireless e-boards over Bluetooth LE -- one firmware, automatic board detection at runtime. With no cable computer present, the gateway can also masquerade as a ChessLink or Chessnut board itself, so wireless chess software can connect directly.

  • Supported e-boards: MILLENNIUM Supreme T2 BT, Chessnut Air/GO/Pro, ManyaCynus camera-vision robot (including castling, en passant, promotion)
  • Standalone mode: no cable computer needed -- the gateway advertises itself as a ChessLink or Chessnut board over BLE for wireless chess software (PicoChess, BearChess, Chess PGN Master)
  • Automatic PGN game recording, including checkmate detection and a manual result-signal gesture
  • USB game retrieval via a simple physical gesture and a standalone Windows tool
  • Flash directly from your browser -- no toolchain required (below)

Installation

  1. Connect the ESP32-C3 SuperMini to your computer via USB.
  2. Use Google Chrome or Microsoft Edge.
  3. Click Connect above.
  4. Select the ESP32-C3 serial device.
  5. Confirm the installation and wait until flashing is complete.
  6. Disconnect and reconnect USB power.

Target: ESP32-C3 SuperMini compatible boards
